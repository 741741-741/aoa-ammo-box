# Ammo Box Mod 1.0.1

## Features
- 27 slots storage for 7 types of AoA3 ammunition (Limonite Bullet, Metal Slug, Spreadshot, Cannonball, Balloon, Discharge Capsule, Pop Shot)
- Equips in Curios API back slot
- Full-auto guns consume ammo directly from the ammo box (-1 durability per shot)
- Semi-auto guns use vanilla inventory (skip ammo box)
- Crafting recipe: 5 Limonite Ingots + 4 Leather (3x3 pattern)
- Durability: 2000

## Fixes
- Fixed semi-auto gun compatibility issues
- Optimized full-auto ammo consumption logic
- Added 32x32 HD texture

## Requirements
- Minecraft 1.16.5
- Forge 36.2.42
- Curios API 1.16.5-4.1.0.0
- AoA3 3.6.11
