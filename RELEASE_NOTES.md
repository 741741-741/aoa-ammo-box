# Ammo Box Mod 1.0.1

## Features
- 27 slots storage for 7 types of AoA3 ammunition (Limonite Bullet, Metal Slug, Spreadshot, Cannonball, Balloon, Discharge Capsule, Pop Shot)
- Equips in Curios API back slot
- Crafting recipe: 5 Limonite Ingots + 4 Leather

## Requirements
- Minecraft 1.16.5
- Forge 36.2.42
- Curios API 1.16.5-4.1.0.0
- AoA3 3.6.11

## Bug
If you encounter an issue where ammo cannot be consumed from the ammo box, place one of the same ammunition type in your inventory.
