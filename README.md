# Ammo Box Mod

A portable ammo box for Advent of Ascension (AoA3) that stores ammunition in the back slot.

## Features
- 27 slots storage for 7 types of AoA3 ammunition
- Equips in Curios API back slot
- Full-auto guns consume ammo directly from the ammo box
- Craftable: 5 Limonite Ingots + 4 Leather
- Durability: 2000

## Requirements
- Minecraft 1.16.5
- Forge 36.2.42
- Curios API 1.16.5-4.1.0.0
- AoA3 3.6.11

## Known Issues
- If ammo cannot be consumed from the ammo box, place one of the same ammunition type in your inventory
